# Soporte con IA para clientes de webs

Plataforma de soporte para los clientes de las webs de Daniel Escalante:
- un asistente de IA atiende las incidencias y resuelve lo sencillo con la base de conocimiento;
- lo que no puede resolver lo convierte en un ticket bien descrito;
- Daniel gestiona los tickets desde un panel con prioridades, estados, respuestas en tiempo real y métricas.
